# 🌿 Arockia Joyston — Personal Portfolio

A nature-themed personal portfolio website built with pure **HTML**, **CSS**, and **Vanilla JavaScript** — no frameworks, no dependencies.


---

## 📁 File Structure

```
portfolio/
├── index.html       ← Main HTML structure
├── style.css        ← All styles, animations & responsive design
├── script.js        ← Interactivity, animations & effects
├── joy.jpg          ← Profile photo 
└── README.md        ← You are here
```

---

## ✨ Features

- 🌿 **Nature / Forest theme** — deep greens, amber accents, botanical SVG art
- 🖱️ **Custom cursor** — glowing dot + trailing ring
- 🍃 **Floating particle canvas** — animated background particles
- ⌨️ **Terminal typewriter** — animated code intro on the hero
- 📜 **Marquee ticker** — scrolling tech stack band
- 📊 **Animated skill bars** — triggered on scroll
- ⏱️ **Journey timeline** — learning path with animated entries
- 📱 **Fully responsive** — mobile, tablet, desktop
- 🎨 **Scroll progress bar** — top of the page
- 🔢 **Animated counters** — LeetCode stats
